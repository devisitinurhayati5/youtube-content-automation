# YouTube Content Automation

Pusat workflow untuk mempercepat produksi konten YouTube, terutama musik, thumbnail, SEO, dan upload planning.

## Struktur
- `prompts/thumbnails/` — prompt thumbnail 16:9
- `prompts/backgrounds/` — prompt background musik
- `prompts/titles/` — template judul
- `seo/` — keyword, tag, hashtag
- `templates/` — template deskripsi dan checklist
- `tools/` — script otomatisasi

## Workflow
1. Tentukan niche dan target audience.
2. Generate judul dan keyword.
3. Generate prompt visual.
4. Siapkan deskripsi, tag, dan hashtag.
5. Jalankan checklist sebelum upload.

Repository ini dibuat sebagai workspace yang dapat dikembangkan menjadi sistem otomatisasi konten yang lebih lengkap.
